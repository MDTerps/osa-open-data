# OSA open data

Monthly copies of the open catalogs published by two independent comparison sites. Each folder
holds the catalog as CSV (exactly as served on the site), the same rows as JSON, and a README
with the field list, the as-of date and the license.

- [saunas/](saunas/): Home Sauna Prices and Specs, from SaunaCosts (https://saunacosts.com/). Source page https://saunacosts.com/data/, methodology https://saunacosts.com/methodology/.
- [evchargers/](evchargers/): Home EV Charger Prices and Specs, from EV Charger Index (https://evchargerindex.com/). Source page https://evchargerindex.com/data/, methodology https://evchargerindex.com/methodology/.
